## Sensor HAV

### Implementasi

* Rangkaian modul ADXL345
* Algoritma akuisisi percepatan tiga sumbu dengan ODR 3200 Hz

### Verifikasi

* Perbandingan hasil pembacaan percepatan tiga sumbu dengan kalibrator getaran
* Fungsi *self-test* internal sensor

### Catatan Perbaikan

## Pemroses Tepi

### Implementasi

* Rangkaian modul ESP32-S3
* Algoritma filter Wh dan fungsi kalkulasi RMS per detik

### Verifikasi

* Perbandingan matematis nilai keluaran RMS dengan hasil simulasi MATLAB

### Catatan Perbaikan

## BLE Transceiver

### Implementasi

* Algoritma konfigurasi BLE GATT Server

### Verifikasi

* Stabilitas transfer data nirkabel
* Mekanisme pemulihan koneksi otomatis

### Catatan Perbaikan

## Manajemen Daya HAV

### Implementasi

* Rangkaian proteksi baterai Li-Po 103040 3.7V 1200mAh
* Rangkaian modul TP4056
* Rangkaian LDO MCP1700

### Verifikasi

* *Drain test*
* Stabilitas tegangan keluaran LDO saat beban puncak
* Proteksi hubung singkat / pengosongan berlebih

### Catatan Perbaikan

## Sensor WBV

### Implementasi

* Rangkaian modul ADXL345
* Algoritma akuisisi percepatan tiga sumbu dengan ODR 3200 Hz

### Verifikasi

* Perbandingan hasil pembacaan percepatan tiga sumbu dengan kalibrator getaran
* Fungsi *self-test* internal sensor

### Catatan Perbaikan

## Pemroses Utama

### Implementasi

* Rangkaian modul ESP32-S3
* Algoritma *multitasking* berbasis FreeRTOS untuk pembobotan filter Wk/Wd beserta fungsi kalkulasi RMS per detik, penerimaan BLE, pemantauan baterai, penulisan ke kartu SD, dan transisi *state* FSM

### Verifikasi

* Pemantauan waktu eksekusi *task* untuk membuktikan tidak terjadinya *priority inversion* dan/atau *system crash* saat perekaman aktif

### Catatan Perbaikan

## BLE Receiver
